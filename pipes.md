For any pipe that originates in the HOA/common grounds, passes through a Condo building wall/slab, and continues into a Unit, here is my practical shared-responsibility guideline with explicit boundaries:

1) HOA responsibility (default):
The HOA is responsible for the pipe and all work outside the building footprint, including underground/exterior portions, fittings/valves in common grounds, and any restoration of grounds/landscaping/paving disturbed by the repair.

2) Condo responsibility (building envelope & structure only):
The Condo Association is responsible only for the building envelope and structural interface where the pipe passes through, specifically: core drilling/cutting, sleeves, firestopping, sealing/waterproofing, masonry/drywall/plaster repair in common areas, and restoring the wall/slab/penetration back to code (including any required inspections).
This does not mean the Condo “owns” the system being serviced, and it does not include sprinkler system design, sprinkler scope decisions, sprinkler vendor control, or sprinkler system funding unless the issue is strictly inside the building and solely a building structural item.

3) Unit Owner responsibility (inside-unit only):
The Unit Owner is responsible for the portion inside the Unit that serves only that Unit, including shutoffs/fixtures, and restoration of interior finishes inside the Unit (paint, trim, flooring, etc.).

Default rule to avoid disputes/delays:
If there is a conflict on boundary interpretation, the responsibility should temporarily default to the HOA so repairs proceed immediately and damage is prevented; any cost allocation can be reconciled afterward by citing the governing documents.
